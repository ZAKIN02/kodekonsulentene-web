# BrandScript Output Template

Use this exact structure when delivering a completed BrandScript. Keep every line short and plain. No em dashes anywhere.

---

# BrandScript: [Company / Product Name]

## Controlling Idea
[One sentence. The moral of the brand's story that every message reinforces.]

## One-Liner
[1-2 sentences: Character + Problem + Plan + Success. A stranger could repeat it.]

---

## 1. A Character
**Customer:** [who they are, one line]
**They want:** [the ONE thing]
**Aspirational identity:** [who they want to become / how they want to be seen]

## 2. Has a Problem
**Villain:** [the single root cause, personified]
**External:** [the tangible problem]
**Internal:** [how it makes them feel]
**Philosophical:** [why it's just plain wrong]

## 3. Meets a Guide
**Empathy:** [one statement showing you understand the frustration]
**Competency:** [2-4 concrete proof points]

## 4. Who Gives Them a Plan
**Plan name (optional):** [e.g., "The Clarity Roadmap"]
1. [Customer action step]
2. [Customer action step]
3. [Customer action step]
**Agreement plan (optional):** [promises that disarm specific fears]

## 5. And Calls Them to Action
**Direct CTA:** [2-4 word imperative]
**Transitional CTA:** [the free value offer, with its title]

## 6. That Helps Them Avoid Failure
- [Concrete consequence 1]
- [Concrete consequence 2]
- [Optional consequence 3]

## 7. And Ends in Success
- [Specific, visual result 1]
- [Specific, visual result 2]
- [Specific, visual result 3]

**Identity transformation:** From [old identity] → To [new identity]
(Render the transformation with the word "to" rather than an arrow if the user prefers plain text.)

---

## Sound Bites (repeat these everywhere)
- [Tagline candidate]
- [Empathy line]
- [Stakes line]
- [Success line]

## Suggested Next Steps
[Offer: website wireframe copy, email sequence, elevator pitch, sales script. See applications.md.]
